LinkedIn Vacancy Scraper
========================

Documentation for the scraper, its data model, and the tools built on top
of it (match scoring, and the web app). This is the project's maintained
documentation surface -- ``CLAUDE.md`` in the repo root stays a short
orientation file for working in the codebase, not a duplicate of this
content.
